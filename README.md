# Coffee Shop

Site de uma cafeteria fictícia, com cabeçalho fixo, menu de navegação para celular, vitrine de produtos, avaliações e formulário de contato.

Projeto de estudo de 2023 (HTML, CSS e JavaScript), mantido aqui como registro da minha evolução.

## Como rodar

Abra o `index.html` no navegador.

## O que pratiquei

- Layout responsivo com Flexbox e Grid
- Menu mobile com JavaScript
- Organização de um site de várias seções
